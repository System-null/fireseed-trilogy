# Fireseed Arweave Adapter (DIY Path)
# Fireseed Arweave 适配器（自助路径）

## What this is / 这是什么

- **English:** A high-friction, self-hosted path for technical users who want to upload Fireseed capsule ZIPs to Arweave (or Bundlr) with their own wallets and gateways. No hosted upload, no key handling, and no gas sponsorship are provided by this repo.
- **中文：** 这是一个面向技术用户的「高门槛、完全自助」上链路径。需要你自行管理私钥和网关，仓库不会代为托管、签名或代付费用。

## Prerequisites / 前置条件

- An Arweave wallet JWK keyfile (or a Bundlr-compatible setup you control).
- A Fireseed capsule ZIP generated by `/capsule/create`.
- Basic CLI familiarity.

## Recommended file & tags / 推荐文件与标签

Upload the **entire `fireseed-capsule-*.zip`** as the Arweave/Bundlr data payload.

Recommended tags (example):

```jsonc
[
  { "name": "App-Name", "value": "FireseedCapsule" },
  { "name": "Fireseed-Capsule-Id", "value": "<capsuleId>" },
  { "name": "Fireseed-Schema-Version", "value": "<schemaVersion>" },
  { "name": "Fireseed-Hash-SHA256", "value": "<sha256-of-zip>" },
  { "name": "Content-Type", "value": "application/zip" }
]
```

标签说明（中文）：

- `App-Name: FireseedCapsule` — 方便后续检索或过滤 Fireseed 相关交易。
- `Fireseed-Capsule-Id: <capsuleId>` — 对应你的胶囊 ID。
- `Fireseed-Schema-Version: <schemaVersion>` — 例如 `0.3.x`，与生成 ZIP 时的 schema 版本一致。
- `Fireseed-Hash-SHA256: <sha256-of-zip>` — ZIP 文件的 SHA256 校验，便于校验完整性。
- `Content-Type: application/zip` — 告诉网关内容类型。

## Example with Bundlr CLI / 使用 Bundlr CLI 的示例（伪示例）

> This is a schematic example. Refer to Bundlr/Arweave official docs for exact flags and authentication.
> 下方命令仅作示意，具体参数以 Bundlr / Arweave 官方文档为准。

```bash
bundlr upload fireseed-capsule-abc123.zip \
  -w /path/to/arweave-keyfile.json \
  -t '[{"name":"App-Name","value":"FireseedCapsule"},{"name":"Fireseed-Capsule-Id","value":"abc123"},{"name":"Fireseed-Schema-Version","value":"0.3.x"},{"name":"Fireseed-Hash-SHA256","value":"<sha256>"},{"name":"Content-Type","value":"application/zip"}]'
```

A successful upload returns a `txId`. Typical gateway URL:

- `https://arweave.net/<txId>`

上传成功后会得到 `txId`，常见访问方式：

- `https://arweave.net/<txId>`

## How to register the replica in your manifest / 如何在 Manifest 中登记副本

1) Export your manifest from `/lab` and edit manually, **or** edit the capsule workspace JSON directly if you know what you are doing.
2) Add an entry to `replicas` using `ar://<txId>` as the location.

Example snippet:

```jsonc
{
  "capsuleId": "abc123",
  "replicas": [
    {
      "adapterId": "arweave-manual",
      "location": "ar://<txId>",
      "lastUpdatedAt": "2025-11-25T12:34:56Z",
      "notes": "Uploaded via self-hosted Bundlr CLI"
    }
  ]
}
```
